# anothercat7

Hi!  I'm anothercat7, a programmer and computer science student who cares
about [privacy][1], supports [free software][2], and isn't afraid to speak
out against [digitization compulsion and enforcement][3] in all its many
forms.

As you can probably infer, I think technology is interesting but dangerous;
it is very important to use it ethically.  "Don't be evil" and "Do the right
thing" would have been great mottos if Google and Alphabet had acted on
them — but they didn't because it was not really their top priority.

> Do the right thing, *no matter what*.

That's the motto I aspire to, and I think the world would be in much better
hands if every programmer out there did too.

Oh, and in case you're wondering: you won't find any AI generated code in
any of my repositories.  I'm a programmer, not a switchboard operator for
AI generated slop.
